Canvas + Inspect

An internal design review tool I built with Claude Code to give stakeholders a familiar way to review designs in the browser.

The challenge

Our stakeholders were used to reviewing work in Figma. As more designs took shape in code, they still needed a shared place to compare screens, inspect details, and leave feedback on specific elements.

The solution

A freeform canvas brings the design flows together. An inspection and commenting overlay lets reviewers work directly on the UI and hand structured feedback back to Claude Code.

ApproachKey decisionSolution

The Approach

A board for comparing real screens

I put flows, screens, and variations on one zoomable board. Each preview runs the actual component with sample data, so stakeholders can review realistic states and compare alternatives side by side.

An inspector for reviewing details

Stakeholders can select an element to see its size, spacing, and typography. I kept these tools in the browser so reviewers could carry out familiar checks on code-built screens.

The Key Decision

Keep feedback attached to the UI

A pinned comment stays with its element as the board moves or zooms. Open comments can be copied as structured feedback that includes the element label, selector, and size. That gives Claude Code a concrete starting point for editing the source.

The Solution

Make sharing part of the review

Reviewers can capture a screen or element at full resolution regardless of zoom. For a live walkthrough, presentation mode follows the board in reading order and returns to the previous canvas view on exit.
